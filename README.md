# Ridgeway Roofing & Construction — demo site

A full-site demo for **Terry Huggins**, trading as Ridgeway Roofing and Construction in
**Marion, Ohio**, built by [60 Minute Sites](https://60minutesites.com).

Static HTML/CSS/JS. No build step to deploy, no dependencies, no framework — host it anywhere
(Netlify, GitHub Pages, any static host).

**34 pages**: home · services index · 8 service pages · about · contact · work · service area
· 16 town pages · thank-you · sitemap · 404 · photo credits.

> **Read [`DEMO-NOTES.md`](DEMO-NOTES.md) before changing anything.** It records what came from the
> actual phone call, what is inferred, and what is deliberately left blank (reviews, licence claims,
> years in the trade, prices). Those blanks are on purpose.

## Preview locally

```bash
python3 -m http.server 8479
```

then open <http://localhost:8479>.

## How it is built

Every `.html` file in this repo is generated by `_generator/build.py` from the data at the top of
that file — business details, the eight services, the sixteen towns, the gallery and the photo
credits. To change copy, edit the generator and rebuild:

```bash
python3 _generator/build.py
```

Hand edits to `assets/css/main.css`, `assets/js/main.js` and `assets/js/chatwidget.js` survive a
rebuild. **Page HTML does not** — it is overwritten every time.

The single most useful thing to know: business details live in one block of constants at the top
of `_generator/build.py` (`BIZ`, `OWNER`, `PHONE`, `TEL`, `SMS`, `EMAIL`, `CITY`, `DOMAIN`, `FORM`).
Change one there and it changes on all 34 pages.

## Design

Modelled on the [Northline Property Services](https://github.com/corbanCodes/northline-property-services)
build at the client's request — same page architecture, same component set, same Archivo / Inter
type system. Different palette, different imagery, and no video anywhere (Terry has none).

Palette: Slate `#2B3A48` · Ink `#151C23` · Amber `#E08A3C` · Copper `#A65A2A` · Bone `#F6F3ED`.

## Photos

**Every photograph is stock, none are Terry's work.** Photographers, licences and a replacement
guide are in [`ATTRIBUTION.md`](ATTRIBUTION.md) and published on the site at `/credits.html`.
The Work page says so in a box before the visitor sees a single image.

## Demo wiring

- `noindex, nofollow` on every page plus a blocking `robots.txt`, so this can never outrank a real
  Ridgeway site
- Demo banner on every page, plus a second disclosure in the footer
- Contact form posts to the shared 60MS Formspree test endpoint, not to Terry, and says so
- Chat widget runs in offline mode

Full detail, and how to switch each of these to live, is in `DEMO-NOTES.md`.

## Deploy

Netlify → **Import from GitHub** → pick this repo → Deploy. `netlify.toml` sets the publish
directory and cache headers; there is nothing to configure.
