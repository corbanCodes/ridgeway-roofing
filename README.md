# Ridgeway Roofing & Construction

Website for **Terry Huggins**, trading as Ridgeway Roofing and Construction in **Marion, Ohio**,
serving North Central Ohio — Marion, Delaware, Mansfield and Columbus.

Built by [60 Minute Sites](https://60minutesites.com). Static HTML/CSS/JS — no build step to
deploy, no dependencies, no framework. Host it anywhere (Netlify, GitHub Pages, any static host).

**43 pages**: home · services index · 9 service pages · about · contact · work · reviews ·
service area · 24 town pages · thank-you · sitemap · 404, plus `sitemap.xml`.

> **Read [`SITE-NOTES.md`](SITE-NOTES.md) before this goes on a live domain.** The seven reviews
> are placeholder copy, not real testimonials, and the contact form still points at a test
> endpoint. Both are one-line fixes; both matter.

## Preview locally

```bash
python3 -m http.server 8479
```

then open <http://localhost:8479>.

## How it is built

Every `.html` file plus `sitemap.xml` and `robots.txt` is generated by `_generator/build.py` from
the data at the top of that file — business details, the nine services, the 24 towns, the reviews
and the gallery. To change copy, edit the generator and rebuild:

```bash
python3 _generator/build.py
```

Hand edits to `assets/css/main.css` and `assets/js/main.js` survive a rebuild. **Page HTML does
not** — it is overwritten every time.

Business details live in one block of constants at the top of the generator (`BIZ`, `OWNER`,
`PHONE`, `TEL`, `SMS`, `EMAIL`, `CITY`, `REGION`, `HUBS`, `DOMAIN`, `FORM`). Change one there and
it changes on all 43 pages.

## Design

Palette: Slate `#2B3A48` · Ink `#151C23` · Orange `#FE5D03` (sampled from the client's logo) ·
Rust `#B8430A` · Bone `#F6F3ED`. Type: Archivo (headings, expanded) and Inter (body).

Page architecture and component set follow the
[Northline Property Services](https://github.com/corbanCodes/northline-property-services) build,
at the client's request.

`main.css` has two commented specificity traps in it — read the note in `SITE-NOTES.md` before
adding rules to the header or the footer.

## Photos

Five are Terry's own, in `client-provided-pictures/` (HEIC, portrait, with EXIF rotation — convert
with `magick <file> -auto-orient`, not `sips`). They lead the home page and the gallery and carry
the metal and commercial roofing pages. The rest is Unsplash library imagery standing in for the
trades he has no photos of yet. `SITE-NOTES.md` lists what to ask him for next and in what order.

## Deploy

Netlify → **Import from GitHub** → pick this repo → Deploy. `netlify.toml` sets the publish
directory and cache headers; there is nothing to configure.
